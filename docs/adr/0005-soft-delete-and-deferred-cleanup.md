# 0005. 프로젝트·서비스 삭제는 소프트 삭제로 하고 리소스 정리는 미룬다

- 상태: 수락됨
- 날짜: 2026-10-01
- 결정자: 김지민

## 배경
서비스를 삭제하면 이론상 실행 중 Pod, 이미지, 도메인도 정리해야 한다. 이 정리는 빌드·배포 엔진(현겸님 담당) 작업이다.

## 검토한 선택지
1. 하드 삭제 → 배포 이력·릴리스 참조가 끊긴다.
2. 소프트 삭제(`is_deleted`, `deleted_at`) + 정리 작업은 이후 단계.

## 결정
선택지 2. 프로젝트 삭제는 소속 서비스도 함께 소프트 삭제한다. 이름 유일성은 `WHERE NOT is_deleted` 부분 유니크 인덱스라 삭제한 이름은 다시 쓸 수 있다. 삭제된 리소스는 API 에서 `404` 다.

## 결과
- 이력은 보존된다.
- **후속 과제:** 삭제된 서비스의 실행 리소스를 정리하는 엔진 작업(예: RECONCILE/DESTROY job). 그 전까지는 실제 리소스가 남을 수 있다.
